关于软件

让只接 USB 的设备，变成局域网里能用标准 adb 命令访问的网络设备。
电脑 B
用 adb 命令操作
TCP 局域网
电脑 A（本程序）
设备通过 USB 接在这里
USB
设备 C
无需改动、无需 root
1 在电脑 A 上启动本程序，点「启动桥」
2 在电脑 B 上执行 adb connect 电脑A的IP:15555
3 之后像普通设备一样用：adb -s 电脑A的IP:15555 shell
! 端口用 15555，不要用 5555（会与模拟器冲突）
