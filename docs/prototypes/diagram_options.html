为什么没有 SVG 方案

Slint 的 SVG 渲染走 usvg，而它的 Options::default() 用的是空的 fontdb （fontdb::Database::new()，没有加载任何系统字体）。 所以 SVG 里的 <text> 因为找不到字体完全不渲染 —— 「电脑 B」「USB」这些字一个都画不出来。

结论：走 SVG 的话文字仍然得用 Slint 的 Text 叠上去、 还得跟图形精确对位，比现在更麻烦。两种方案里 方案 B 的图标用几何图形就能拼出来（显示器=圆角矩形+底座，芯片=矩形+引脚）， 不需要任何图片资源。
