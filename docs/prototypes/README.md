# 界面原型

这里是图形界面的**设计过程稿**（纯 HTML/CSS，可直接用浏览器打开）。

它们不是运行时依赖——Slint 版界面（`rust/ui/main.slint`）已经实现完毕，
这些 HTML 是当初用来**确认视觉方案**的，保留下来是为了后续迭代界面时
有个直观的参照，不必从零重新讨论配色与布局。

| 文件 | 内容 |
|---|---|
| `ui_prototype.html` | 主界面的完整原型：控制台 / 会话 / 运行日志 / 参数设置 / 诊断工具 / 关于软件 六个页面 |
| `about_page_prototype.html` | 「关于软件」页的单独稿（排版与信息层级） |
| `diagram_options.html` | 控制台页拓扑图的几种画法对比稿 |

## 与最终实现的关系

最终选的是**声明式**界面方案（Slint），而不是即时模式方案 —— 原因之一
正是这些原型里的视觉效果在即时模式框架上难以复现。两者差异与实际约束
记录见 `rust/README.md` 的「界面实现的四条硬约束」。
